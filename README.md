# คู่มือใช้งานเว็บไซต์โปรไฟล์ (index.html)

คู่มือนี้อธิบายวิธีแก้ไข ปรับแต่ง และเผยแพร่เว็บไซต์โปรไฟล์หน้าเดียวของ Komsan Yinghan (ไฟล์ `index.html`) สำหรับคนที่ไม่เคยเขียนเว็บมาก่อนก็ทำตามได้

## 1. ภาพรวมของไฟล์

- เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งโปรแกรมหรือ build ใด ๆ ดับเบิลคลิกเปิดในเบราว์เซอร์ได้ทันที
- CSS (ส่วนตกแต่ง) อยู่ในแท็ก `<style>` ด้านบน และ JavaScript มีแค่บรรทัดเดียวท้ายไฟล์ สำหรับใส่ปีลิขสิทธิ์อัตโนมัติ
- ฟอนต์ (IBM Plex Sans Thai, IBM Plex Mono, Fraunces) โหลดจาก Google Fonts จึงต้องต่ออินเทอร์เน็ตจึงจะเห็นฟอนต์ครบ ถ้าออฟไลน์จะใช้ฟอนต์สำรองของเครื่อง
- รองรับมือถือ และสลับโหมดสว่าง/มืดตามการตั้งค่าเครื่องอัตโนมัติ

## 2. โครงสร้างหน้าเว็บ

ในไฟล์จะมีคอมเมนต์ขั้นแต่ละส่วนในรูปแบบ `<!-- ===== HERO ===== -->` ใช้ Ctrl+F ค้นหาชื่อส่วนเพื่อกระโดดไปแก้ได้เร็วที่สุด

| ส่วน | คอมเมนต์ที่ใช้ค้นหา | เนื้อหา |
|---|---|---|
| แถบเมนู | `<header>` | โลโก้ ลิงก์เมนู ปุ่มติดต่อ |
| หัวเรื่อง | `HERO` | สถานะว่างรับงาน ตำแหน่ง ข้อความหลัก ปุ่ม ตัวเลขสถิติ |
| บริการ | `SERVICES` | การ์ดบริการ 4 ใบ |
| ประสบการณ์ | `EXPERIENCE` | ไทม์ไลน์ประวัติการทำงาน |
| ทักษะ | `SKILLS` | กลุ่มทักษะแบบป้ายชื่อ (chip) |
| การศึกษา | `EDUCATION` | วุฒิการศึกษา การอบรม ใบรับรอง |
| ขั้นตอนการทำงาน | `PROCESS` | 4 ขั้นตอน |
| เกี่ยวกับผม | `ABOUT` | รูปและข้อความแนะนำตัว |
| ติดต่อ | `CONTACT` | ปุ่มอีเมล ปุ่มโทร |

## 3. วิธีแก้ไขเนื้อหา

ใช้โปรแกรมแก้ข้อความ เช่น VS Code, Notepad++ หรือ Notepad แล้วแก้เฉพาะข้อความที่อยู่ **ระหว่างแท็ก** เช่น `<h3>ระบบเครือข่าย</h3>` แก้คำว่า "ระบบเครือข่าย" ได้ แต่อย่าลบเครื่องหมาย `<` `>` หรือแท็กปิด `</h3>` เมื่อแก้เสร็จให้บันทึกไฟล์แล้วกด F5 ที่หน้าเบราว์เซอร์เพื่อดูผล

### 3.1 ข้อมูลที่ควรแก้เป็นอย่างแรก

- **Title และคำอธิบายเว็บ**: อยู่ใน `<title>` และ `<meta name="description">` ด้านบนสุด เป็นข้อความที่แสดงบนแท็บเบราว์เซอร์และผลค้นหา Google
- **สถานะว่างรับงาน**: ในส่วน HERO บรรทัด `ว่างรับงาน · จันทบุรี` ถ้าไม่ว่างแล้วให้แก้หรือลบบรรทัดนี้ เพื่อไม่ให้ข้อมูลล้าสมัย
- **ตัวเลขสถิติ** (GPA, ปีเริ่มงาน, จำนวนแบรนด์): อยู่ใน `<div class="stats">` ปรับให้ตรงข้อมูลจริงเสมอ
- **อีเมลและเบอร์โทร**: ในส่วน CONTACT มี 3 จุดที่ต้องแก้ให้ตรงกัน คือ `mailto:...` ข้อความ `โทร ...` และบรรทัดอีเมลด้านล่าง ส่วนเบอร์ใน `tel:` ให้เขียนติดกันไม่มีขีด

### 3.2 เพิ่ม ลบ หรือแก้รายการ

ทุกรายการเป็นบล็อกที่ซ้ำรูปแบบกัน วิธีเพิ่มคือ **คัดลอกบล็อกเดิมทั้งก้อน** แล้ววางต่อท้าย จากนั้นแก้ข้อความ

- **การ์ดบริการ**: คัดลอก `<div class="card">...</div>` ทั้งก้อนในส่วน SERVICES แล้วแก้เลขลำดับ (`01`, `02`, ...) เอง เพราะเลขนี้พิมพ์ไว้ในไฟล์ ไม่ได้นับอัตโนมัติ
- **ประสบการณ์งาน**: คัดลอก `<li>...</li>` หนึ่งก้อนในส่วน EXPERIENCE โดยเรียงงานล่าสุดไว้บนสุด
- **ทักษะ**: เพิ่มป้ายด้วย `<li>ชื่อทักษะ</li>` ในกลุ่มที่ต้องการ
- **ขั้นตอนการทำงาน**: คัดลอก `<div class="step">...</div>` ตัวเลข 01, 02 จะนับให้อัตโนมัติ
- **ลบรายการ**: ลบทั้งบล็อกตั้งแต่แท็กเปิดถึงแท็กปิดของมัน

### 3.3 ใส่รูปโปรไฟล์

1. สร้างโฟลเดอร์ `images` ไว้ข้างไฟล์ `index.html` แล้วใส่รูปชื่อ `me.jpg` (แนะนำรูปสี่เหลี่ยมจัตุรัส ขนาดไม่เกิน 500 KB)
2. ในส่วน ABOUT หาบรรทัด `<div class="photo">KY</div>`
3. แก้ตัวอักษร KY เป็น `<img src="images/me.jpg" alt="Komsan Yinghan">`

ผลที่ได้คือ `<div class="photo"><img src="images/me.jpg" alt="Komsan Yinghan"></div>`

### 3.4 ปุ่มดาวน์โหลด CV

ปุ่มนี้ลิงก์ไปที่ `cv.pdf` ต้องวางไฟล์ PDF ชื่อ `cv.pdf` ไว้โฟลเดอร์เดียวกับ `index.html` ถ้ายังไม่มีไฟล์ ปุ่มจะขึ้นหน้า error ให้ลบปุ่มนี้ออกชั่วคราว (ลบบรรทัด `<a href="cv.pdf" ...>` และคอมเมนต์ด้านบนของมัน)

### 3.5 เมนูด้านบน

- เมนูอยู่ในแท็ก `<ul class="links">` แต่ละรายการลิงก์ไปยังส่วนที่มี `id` ตรงกัน เช่น `#services` ไปที่ `<section id="services">`
- ถ้าเพิ่มส่วนใหม่ ให้ตั้ง `id` ให้ส่วนนั้น แล้วเพิ่มลิงก์ในเมนู
- บนจอมือถือ (กว้างไม่เกิน 720 พิกเซล) เมนูลิงก์จะถูกซ่อน เหลือเฉพาะโลโก้และปุ่ม "ติดต่อ" เป็นการออกแบบไว้เช่นนั้น

## 4. วิธีปรับสีและฟอนต์

### สี

อยู่ในบล็อก `:root{ ... }` ต้น CSS ค่าที่ใช้บ่อย:

- `--accent`: สีหลัก (ปุ่ม ลิงก์ เส้นเน้น) ปัจจุบันเป็นสีน้ำเงิน `#1a6fd8`
- `--bg`: สีพื้นหลังหน้า
- `--surface`: สีพื้นการ์ด
- `--text` และ `--muted`: สีตัวอักษรหลักและตัวอักษรรอง
- `--ok`: สีจุดสถานะว่างรับงาน (เขียว)

โหมดมืดมีชุดสีแยกอีกสองที่ (ใน `@media (prefers-color-scheme: dark)` และ `:root[data-theme="dark"]`) หากเปลี่ยน `--accent` ควรเปลี่ยนค่าในโหมดมืดให้เป็นโทนเดียวกันด้วย ไม่เช่นนั้นสีจะไม่ตรงกันเมื่อสลับโหมด

### ฟอนต์

ฟอนต์ถูกเรียกในแท็ก `<link href="https://fonts.googleapis.com/...">` และกำหนดใช้ใน CSS ที่ `font-family` ถ้าจะเปลี่ยนฟอนต์ ให้แก้ทั้งสองที่ให้ชื่อตรงกัน และเลือกฟอนต์ที่รองรับภาษาไทย

## 5. ทดสอบก่อนเผยแพร่

- เปิดไฟล์ในเบราว์เซอร์ แล้วคลิกทุกปุ่มและทุกลิงก์เมนูว่าเลื่อนไปถูกส่วน
- กดปุ่มอีเมลและปุ่มโทรบนมือถือว่าเปิดแอปได้ถูกต้อง
- ตรวจเบอร์โทร อีเมล ปีที่ทำงาน และ GPA ให้ตรงกับเอกสารจริง
- ย่อหน้าต่างเบราว์เซอร์ให้แคบ หรือกด F12 แล้วเปิดโหมดมือถือ เพื่อดูหน้าจอเล็ก
- ลองเปิดทั้งโหมดสว่างและโหมดมืด

## 6. วิธีเผยแพร่ขึ้นอินเทอร์เน็ต (ฟรี)

ทุกวิธีต้องตั้งชื่อไฟล์หลักว่า `index.html` พอดี และวางไฟล์เสริม (`cv.pdf`, โฟลเดอร์ `images`) ไว้ในที่เดียวกัน

**ทางที่ 1: Cloudflare Pages หรือ Netlify (ง่ายที่สุด)**

1. สมัครบัญชีฟรี
2. เลือกสร้างโปรเจกต์ใหม่ แบบอัปโหลดไฟล์โดยตรง (Direct Upload หรือ Drag and drop)
3. ลากโฟลเดอร์ที่มี `index.html` ไปวาง แล้วรอไม่กี่วินาที จะได้ลิงก์ เช่น `ชื่อ.pages.dev` หรือ `ชื่อ.netlify.app`
4. เมื่อแก้ไฟล์ ให้อัปโหลดโฟลเดอร์ซ้ำอีกครั้งเพื่ออัปเดต

**ทางที่ 2: GitHub Pages**

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมด
2. ไปที่ Settings > Pages แล้วเลือก Branch เป็น `main` โฟลเดอร์ root
3. รอสักครู่ จะได้ลิงก์รูปแบบ `ชื่อผู้ใช้.github.io/ชื่อ-repo`

หากต้องการชื่อโดเมนของตัวเอง ต้องซื้อโดเมนแยก แล้วผูกกับบริการที่เลือกในหน้าตั้งค่า Custom domain

## 7. ข้อควรระวัง

- **ข้อมูลส่วนตัวเปิดสาธารณะ**: อีเมลและเบอร์โทรอยู่ในไฟล์โดยตรง ใครก็เห็นได้และบอทเก็บไปส่งสแปมได้ ถ้ากังวลให้ใช้อีเมลเฉพาะสำหรับงาน หรือใช้ฟอร์มติดต่อแทน
- **ข้อมูลต้องเป็นจริงและทันสมัย**: โดยเฉพาะสถานะว่างรับงาน GPA และรายการใบรับรอง เพราะลูกค้าหรือผู้สมัครงานอาจตรวจสอบ
- **ห้ามลบเครื่องหมายปิดแท็ก**: ถ้าหน้าเว็บเพี้ยนหลังแก้ มักเกิดจากลบ `</div>` หรือ `</li>` หายไป ให้เทียบกับบล็อกอื่นที่ยังปกติ
- **เก็บสำรอง**: ก่อนแก้ครั้งใหญ่ให้คัดลอกไฟล์เก็บไว้ เช่น `index-backup.html`
- **ปรับปรุงเพิ่มเติม (ถ้าต้องการ)**: เพิ่มไอคอนแท็บ (favicon) และรูปตัวอย่างเวลาแชร์ลิงก์ ด้วยแท็ก `<meta property="og:title">` และ `<meta property="og:image">` ใน `<head>`

## 8. แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| ภาษาไทยเป็นตัวอักษรเพี้ยน | บันทึกไฟล์ไม่ใช่ UTF-8 | บันทึกใหม่แบบ UTF-8 |
| ฟอนต์ไม่เปลี่ยน | ไม่ได้ต่ออินเทอร์เน็ต หรือชื่อฟอนต์สะกดผิด | ตรวจ `<link>` และ `font-family` |
| รูปไม่ขึ้น | พาธผิด หรือชื่อไฟล์ตัวพิมพ์เล็กใหญ่ไม่ตรง | ตรวจ `images/me.jpg` ให้ตรงกับชื่อจริง |
| ปุ่ม CV ขึ้น 404 | ยังไม่ได้วางไฟล์ `cv.pdf` | วางไฟล์ให้ถูกที่ หรือลบปุ่ม |
| แก้แล้วไม่เปลี่ยน | ยังไม่บันทึก หรือแคชเบราว์เซอร์ | บันทึกแล้วกด Ctrl+F5 |
| หลังอัปโหลดขึ้นเว็บแต่หน้ายังเก่า | แคชของบริการโฮสต์ | รอ 1–2 นาทีแล้วรีเฟรชแรง ๆ |
